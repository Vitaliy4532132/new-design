## 1. Главная (`/`)

**Primary keyword**: "разработка серверов майнкрафт под ключ" / "студия майнкрафт серверов"
**H1**: содержит "майнкрафт" кириллицей (см. находку про majoritarian кириллицу), явно квалифицирует аудиторию как владельцев, не игроков.

> Пример направления H1: **"Студия разработки майнкрафт-серверов под ключ"** — не "купить сервер в майнкрафт" (этот хвост ловит игроков на донат/привилегии, не нас).

### Секции (сверху вниз)

1. **Hero**
   - H1 (см. выше) + подзаголовок 50-80 слов, естественно включает "сборки", "плагины", "сайты для серверов" как список того, что делаем
   - Статистика (80+ проектов / 65+ плагинов / 73+ клиентов / 24/7) — реальные цифры от пользователя, иначе TODO-плейсхолдер
   - 2 кнопки: "Оставить заявку" (на shop, с UTM) / "Смотреть портфолио" (якорь)
   - CTA-крючок: *"Хочешь сервер как FunTime, HolyWorld или RealityWorld? Пиши нам — сделаем не хуже."* (разговорная строка, не H-тег)
   - Tech-marquee: Java, Kotlin, Spigot, Paper, Velocity, BungeeCord, MySQL, Redis

2. **Что мы создаём** (H2, карточки на 4-6 услуг)
   - Сборки → /builds (упомянуть "крутые сборки", версии 1.16.5/1.20)
   - Плагины → /plugins
   - Сайты для серверов → /sites
   - Сервер с нуля и оптимизация → /server-setup
   - Построение карты → /map-building
   - Каждая карточка: H3 + 60-80 слов с secondary keyword + теги технологий + "Подробнее →"

3. **Готовые решения** (новый блок, НЕ было в исходном ТЗ)
   - Прямой ответ на спрос "купить плагины майнкрафт" (178), "плагин на чат майнкрафт" (669), "купить сборку майнкрафт" (961)
   - 4 карточки: FurryNick, FurryChat ("плагин на чат для майнкрафт сервера" — именно эта формулировка), SolarAnarchyV2, SolarBox V2
   - Цена + "Купить" → ссылка на thefurry.store/shop с UTM

4. **Как мы работаем** (4 шага: Заявка → Расчёт → Разработка → Сдача и поддержка)

5. **Портфолио** (id=portfolio) — 6 карточек, заполняются пользователем

6. **Отзывы** (id=reviews) — статистика + 6 карточек

7. **FAQ** (id=faq, FAQPage schema) — минимум 8 вопросов, прямой ответ 40-60 слов в первых 1-2 предложениях. Обязательно включить вопрос, снимающий путаницу "купить сервер" (см. ниже).

8. **Финальный CTA + Footer**

### FAQ-кандидаты для Главной (с учётом найденного интента)
- Сколько стоит создать сервер minecraft под ключ?
- Чем вы отличаетесь от бесплатного хостинга типа Aternos? *(закрывает интент "атернос" 67 показов)*
- Я игрок и хочу купить донат на сервере — это к вам? *(явно отсекает нецелевой трафик с "купить сервер в майнкрафт")*
- Работаете ли с готовыми сборками или только с нуля?
- Какие версии minecraft вы поддерживаете?
- Есть ли поддержка после сдачи проекта?
- Как происходит оплата?
- Можно ли купить готовый плагин/сборку без индивидуальной разработки?

## 2. `/builds` — Сборки

**Primary keyword**: "крутые сборки майнкрафт" (1754) — самая частотная точная коммерческая фраза в ядре.
**H1**: должен включать "крутые сборки" + указание на версии (1.16.5/1.20), не нейтральное "сборка сервера".

### Секции
1. Hero/intro — прямой ответ в первых 150 словах (CORE-EEAT C02): что такое сборка, сколько стоит (от 2000₽), что входит
2. **TL;DR / что входит в сборку** (O02) — список: плагины, миры, конфигурация, готовность к запуску за 24ч
3. По типам (H2 каждый): SkyBlock, Survival, Anarchy, BoxPvP, RPG, MiniGames — таблица сравнения (формат "Comparison" из content-structure-templates)
4. **Версии игры** — явный блок с поддерживаемыми версиями (1.16.5, 1.20, 1.21) — нашли явный спрос на версийность
5. Готовые товары — SolarAnarchyV2 (100+ онлайн), SolarBox V2 → ссылка на shop
6. Связка с конкурентами — крючок "хочешь как FunTime/HolyWorld" здесь тоже уместен
7. FAQ (снippet-формат 40-60 слов): "Сколько стоит готовая сборка?", "Чем сборка отличается от сервера с нуля?", "Можно ли купить сборку с экономикой и донатом?"
8. CTA

## 3. `/sites` — Сайты для серверов

**Primary keyword**: "сайты для серверов майнкрафт" (4192) — крупнейший точный кластер в ядре.
**H1**: обязательно снять двусмысленность — "Сайт для ВАШЕГО майнкрафт-сервера" (не "сайт для создания сервера", чтобы не путать с хостинг-интентом).

### Секции
1. Hero — прямой ответ: что за услуга, от 3000₽, что входит (донат-шоп, голосование, личный кабинет)
2. **"Бесплатный шаблон vs индивидуальный сайт"** (H2, формат сравнения) — явно адресует сегмент "бесплатно" (1546 показов), мягко переводит в платный сегмент через аргументы (уникальность, интеграция, SEO)
3. Что входит: лендинг / донат-магазин / личный кабинет / голосование / интеграция EasyDonate
4. Примеры (портфолио сайтов, если есть)
5. FAQ: "Сколько стоит сайт для сервера minecraft?", "Чем платный сайт лучше бесплатного шаблона?", "Можно ли интегрировать существующий донат-магазин?"
6. CTA

## 4. `/server-setup` — Сервер с нуля + Оптимизация

Две услуги на одной странице (апсейл-логика: дешёвая "оптимизация" от 500₽ как входная точка → дорогой "сервер с нуля" как апсейл).

**Primary keyword блока "Оптимизация"**: "оптимизация сервера майнкрафт" (876) + "как оптимизировать сервер майнкрафт" (132)
**Primary keyword блока "Сервер с нуля"**: "сервер minecraft с нуля под ключ"

⚠️ Важно: интент здесь в основном информационный/DIY. Страница НЕ должна звучать как чистый прайс-лист — первая секция должна реально отвечать на "как оптимизировать/настроить" (прямой ответ, CORE-EEAT C02), и только затем предлагать платный вариант "сделаем за вас".

### Секции
1. Hero — два предложения услуг сразу видны (оптимизация от 500₽ / сервер с нуля — по запросу)
2. **"Как оптимизировать сервер minecraft" — мини-гайд прямо на странице** (закрывает 876+132 информационного спроса) → "сделать это самому сложно/долго? Закажите настройку"
3. Сервер с нуля: Velocity/BungeeCord, лобби, кастомные режимы, экономика/права
4. Сравнение Velocity vs BungeeCord (таблица — реальный информационный спрос, низкая конкуренция по Trends)
5. FAQ: "Сколько стоит оптимизация сервера?", "Velocity или BungeeCord — что лучше?", "Сколько времени занимает настройка сервера с нуля?"
6. CTA

## CORE-EEAT чеклист — применять на каждой странице

Из skill `seo-content-writer` (references/instructions-detail.md):
- [ ] Прямой ответ в первых 150 словах
- [ ] TL;DR/ключевые тезисы блок near top
- [ ] H1 → H2 → H3, без пропуска уровней
- [ ] ≥5 точных цифр с единицами измерения на странице (цены, сроки, версии, кол-во онлайна)
- [ ] FAQ с ответами 40-60 слов, FAQPage schema
- [ ] 2-5 внутренних ссылок, 2-3 внешних авторитетных (Spigot/Paper docs)
- [ ] TOC при 3+ H2-секциях
- [ ] Conclusion с одним чётким следующим действием (CTA)
