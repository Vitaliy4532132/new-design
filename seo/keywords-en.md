## Real data (Google Trends + Ahrefs, verified live via browser)

**Ahrefs free Keyword Generator** (no signup — gives exactly 1 query per session, then gates behind signup): `minecraft server development` = **<100/mo US volume**. Confirms this head term is genuinely thin in English; the opportunity is in volume aggregated across many long-tail variants, not any single head term.

**Google Trends** (Worldwide, 12 months) comparing `minecraft server hosting` vs `minecraft plugin development` vs `minecraft server setup` vs `minecraft server builder`: **hosting dominates** (index up to 100, spike in March 2026) while all three dev-service terms sit at <1-2 throughout. This confirms generic "hosting" demand (a different business than ours — people want a host, not a dev studio) vastly outweighs our actual service terms, which is expected for a service niche and reinforces the long-tail strategy below.

**Rising related queries** surfaced under `minecraft server setup`: `java 25` (breakout), `hytale` (breakout), `minecraft server status` (+300%), `floodgate` (+250%), `minecraft server list` (+250%). `floodgate` (Bedrock/Java crossplay compatibility) is a concrete, underused blog angle worth adding: "how to enable Bedrock crossplay on your Minecraft server."

## Highest-opportunity zones

1. **Server builds/packs** (skyblock/anarchy/boxpvp/prison) — competition is marketplace listings (BuiltByBit, Polymart), not SEO-optimized agency pages.
2. **Full server from scratch / proxy setup** — same gap, room for a studio-branded landing page.
3. **Informational long-tail** (pricing, "how to hire", velocity vs bungeecord) — only forum threads and generic hosting blogs rank, not real dev studios.
4. **Server websites/donation stores** — moderately competitive (Fiverr gigs), but no "agency-quality" landing pages.
5. **Plugins** and **Map/world building** are most saturated (Fiverr/BuiltByBit gig density) — need differentiation via specific plugin types or "any style any scale" build commissions rather than head terms.
